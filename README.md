# Survivor — 像素幸存者

一个基于 Unity 的 **2D 像素动漫风 Vampire Survivors-like Rogue-lite 游戏**，拥有丰富的装备收集、多角色皮肤、技能进化树和社群 Boss 玩法。

---

## 项目规模

| 类别 | 数量 |
|------|------|
| 技能系统 | 13 个技能 + 3 个 UR 进化 + 1 个合体形态（太极史莱姆） |
| 角色/皮肤 | 4 个（琪诺露、南筱风、夏无、无罪） |
| Boss 类型 | 10 种（5 基础 + 4 社群 WorldBoss + 1 最终龙王） |

| 普通小怪 | 4 种（蘑菇人、蝙蝠、狼人、史莱姆） |
| 装备总数 | ~79 件（成就/通关/抽卡/好感度/继承） |
| 奇遇事件 | 10 个 |
| 社群 | 4 个（蘑菇/蝙蝠/狼人/史莱姆好感度，均已完整实现） |

## 游戏特色

### 核心玩法
- **自动战斗 + 走位** — 技能自动向最近敌人释放，玩家只需专注于走位和生存
- **升级三选一** — 每次升级弹出三张卡牌：学习新技能 / 强化已有技能 / 提升人物属性；首轮保底全为学习卡
- **鼠标点击移动** — 支持 WASD/方向键 和鼠标左键点击地面移动，N1 开局自动弹出新手教程
- **倍速系统** — 1x/2x/3x 三档切换（3x 需成就装备解锁）
- **冲刺** — 空格键冲刺，可升级无敌/穿怪

### 养成系统
- **抽卡系统** — R / SR / SSR / UR 四档抽卡，软保底机制，SSR 直接影响局内战斗（解锁技能、进化路线、被动属性）
- **装备系统** — 四种装备类型（成就/通关/抽卡/好感度），持久化解锁，跨局生效；存档界面可查看获得条件
- **好感度社群** — 四个社群（蘑菇/蝙蝠/狼人/史莱姆），击败世界 Boss 积累好感度，分 10/50/100 三档解锁装备和被动加成
- **源木与奇遇** — 局内货币源木，消耗 200 触发随机奇遇二选一/三选一，效果包括临时增益、永久加成、技能强化

### 技能进化
- **风之形** — 飓风 + 风箭 → 永久环绕风刃
- **地狱火** — 火球术 + 风箭 → 从天而降的三叉戟
- **亡者领域** — 孢子领域 → 击杀敌人概率复活为永久友军
- **命途:寄生** — 狼人社群好感度解锁，发射寄生触手吸取生命
- **太极史莱姆** — 史莱姆社群好感度解锁「阴史莱姆」+「阳史莱姆」，
  两者同时在场时自动合体：太极印压制（禁止敌人移动）与阴阳双色齐射轮流切换，
  合体/拆分皆有演出；升级卡共享，写作「阴/阳史莱姆」

### 挑战内容
- **14 个难度** — N1 教学局到 N13 终极龙王 + 无尽挂机模式
  - 关键节点：N3 奇遇 · N4 蝙蝠 · N5 门挑战 · N6 世界 Boss · N7 血攻翻倍 · N8 社群挑战
- **10 种 Boss** — 蘑菇人/蝙蝠/狼人/史莱姆/龙王及对应社群世界Boss
- **门挑战** — N5+ 解锁的 13 层递增挑战，每层通关所有技能升级上限永久 +1，全通额外经验效率 +10
- **世界 Boss** — N6+ 开局生成，属性为关底 Boss 两倍且自带回血，击败解锁对应社群
- **营地攻占** — 战场中出现可占领的中立营地，占领后每秒产出源木
- **对局结算** — 4 页翻页面板：概览（总伤害/DPS/最高单击/击杀/承伤/治疗/源木）、
  技能伤害占比排行、击败首领列表、本局技能与新解锁装备；支持方向键与滚轮翻页

### 其他
- **四位角色皮肤** — UR 角色通过抽卡解锁，各有独特被动与开局自带技能
  - 琪诺露（默认·均衡）/ 南筱风（风系）/ 夏无（火系）/ 无罪（亡者领域本命）
- **读档复活** — R 级读档币在死亡时消耗 1 张原地满血复活，每局限一次
- **自动模式** — 成就装备8「不可视之手」解锁，自动选取升级
- **装备积分** — 每次抽卡获积分，可兑换通关装备；无尽模式每分钟额外 +5
- **七彩蘑菇/孢子异变** — 蘑菇敌人50% 概率随机变色
- **内置操作文档** — 15 页图文教程，N1 开局自动弹出，可从暂停菜单随时重开

## 技术栈

- **引擎**：Unity 2022.3+ (C#)
- **渲染**：2D Sprite + SpriteRenderer
- **摄像机**：透视投影，45° 俯视视角
- **物理**：Unity Physics（3D Rigidbody + BoxCollider/SphereCollider）
- **UI**：Unity uGUI + TextMeshPro (heiti SDF 中文字体)
- **素材**：像素动漫风精灵图（chibi Q 版比例，~2.5 头身）
- **持久化**：PlayerPrefs（装备/好感度/难度解锁/教程标记）
- **摄像机**：Cinemachine CinemachineBrain

### 2026-08-05 · 无尽倍率显示 + 火球术攻击范围

**无尽模式在计时器旁显示难度倍率** — 形如 `12:35  血×21 攻×3`。
显示的是**最终实际生效**的倍率（`难度配置 × 奇遇 × 无尽` 三者相乘，与
`enemy.ApplyDifficultyScaling` 公式一致），而非只显示无尽增量——后者会低估实际强度。
结果做缓存，仅在每 5 分钟阶段跳变时重建字符串，避免每帧 GC。

**火球术新增攻击范围**（40，与地狱火一致）— 范围内没有敌人时不释放，
且**不消耗冷却**（`CDkey` 回退 0.12s 做重试节流，敌人一进圈立刻开火）。

实现上把「攻击范围」做成 `Skillbase` 的通用能力（默认 0 = 不限制），
而不是新建 `SkillFireball` 子类——火球术在项目里没有专属脚本类，直接挂的就是
`Skillbase`，改子类就得动场景/预制体上的组件类型，风险远大于收益。

字段特意命名为 `castRange` 而非 `attackRadius`：风箭 / 孢子领域 / 血族血统 /
命途:寄生 / 地狱火 / 阴阳史莱姆 这 **6 个子类各自都已声明了 `attackRadius`**，
基类若用同名字段会在这 6 个类里造成字段隐藏（CS0108）——子类读自己的、
基类读基类的，两值互不相干，Unity Inspector 还会出现重名字段与序列化归属含混。

### 2026-08-04 · 修复「刷不到阴/阳史莱姆升级卡」

**根因**：升级卡改为共享后，卡片图标从 `IconOf(isYin)`（学习卡已加载、必命中缓存）
换成了 `IconTaiji`（**首次加载**）。该路径要在 1024×1024 上做 Blit + BFS抠图，
一旦抛异常就会冒泡到 `Register` 的 `try/catch` 被吞掉 → `RegisterOne` 根本没机会执行
→ `ChoiceUI.skillEntries` 里一个史莱姆 entry 都没有。

现象极具迷惑性：技能明明在（`ApplyEquip11` 是`Register` 之后独立调用的，不受影响），
但升级卡池是空的。

**修复**

- `SlimeFactionAssets.Get()` 全程`try/catch`，**保证永不抛异常**——
  图标只是锦上添花，绝不该阻断卡池注册；拿不到就是没图标，卡片照样进池
- 4 张升级卡逐张`try/catch` 构建，一张失败不拖垮其余三张与整个 entry
- 图标改为最后一步赋值，与卡片可用性彻底解耦
- **新增卡池自愈**：`TaijiSlimeWatcher` 低频轮询，若社群已解锁但ChoiceUI 里没有可用
  entry，就地补注册（最多 3 次）。把"一次性时序"兜成"最终一致"。
  触发条件用「好感度 ≥ 10」而非「玩家已有技能」——后者会死锁：
  注册失败时学习卡也没有，玩家永远学不到技能，条件永不成立
- 注册日志补充 `共享升级卡 N/4 张` 与 `HasUsableEntries`，便于复发时定位

**顺带修正**：`PurgeOldEntries` 原会删掉所有 `learnSkillPrefab == null` 的 entry，
属于越权（可能误删其他系统的 entry），现只删空洞与确认属于阴/阳史莱姆的旧 entry。

### 2026-08-04 · 太极史莱姆节奏调优

- **形态切换改为连续攻击 N 次后再切** — 旧版每次攻击都夹一段合体/分解演出，
  冷却降下来后画面就是太极不停聚散抽搐。现在进入形态只播一次转换动画，
  之后在该形态下连续攻击 N 次才切换。
  `N = 12s ÷ 冷却`（钳制 2~10）：CD 5s→2 次、3s→4 次、2s→6 次、1.5s→8 次。
  用除法而非线性插值，是为了让 `N × 冷却` 恒等 —— 线性插值下形态时长会在
  10s/19.5s/15s 之间乱跳，节奏反而更差。
- **新增最小冷却 1.5s**（`SlimeFactionAssets.MIN_CDTIME`）— 冷却有四处来源
  （升级卡 ×5、好感度 40 档、奇遇、门挑战），叠满可压到 1s 以下，会导致
  ① 转换演出播不完；② 齐射协程相互叠加使射弹指数堆积掉帧。
  五个写入点（升级卡 / 分身同步 / Watcher / 好感度加成 / 兜底同步）统一走 `ClampCD()`。
- **蝌蚪射弹放大 1.5 倍**（0.45 → 0.675 米），命中半径同比跟进（0.55 → 0.78），
  避免"明显穿过敌人却不掉血"的割裂感。

### 2026-08-04 · 史莱姆社群（阴 / 阳 / 太极史莱姆）

第四个社群完整落地，全部走**代码运行时注册**（不依赖 prefab / 场景配置，避免打包后引用丢失）。

**技能**

| | 效果 |
|---|---|
| 阴史莱姆（好感 10） | 召唤太极阴鱼，向范围内敌人连射黑色能量灵弹（低伤高量） |
| 阳史莱姆（好感 50） | 召唤阳鱼，连射白色能量灵弹 |
| **太极史莱姆** | 同时持有两者时**自动合体**，两种攻击轮流切换 |

太极史莱姆循环：`合体 → 太极印 → 分解 → 双色齐射`

- **太极印** — 从敌人头顶高空砸下，**压制期间目标无法移动**；每印重新索敌，目标死亡自动转火
- **双色齐射** — 拆分为阴阳双鱼，同时倾泻黑白灵弹
- 合体/分解为程序化动画，时长与冷却绑定（`AnimScale = CDtime / 5s`），保证一个 CD周期内演完
- **学习卡独立、升级卡共享**：升级卡只建一套（伤害/冷却/数量/范围），写作「阴/阳史莱姆」；
  `数量` 同时决定每轮射弹数与太极印次数

**好感度奖励**

```
10 经验效率+5 ⊕阴史莱姆   20攻击+10   30 移速+240 冷却-20%
50 防御+2⊕阳史莱姆   60 范围+10   70 闪避+180 数量+5
90 回血+1                100 ⊕太极两仪（太极图宠物 + 开局自带太极史莱姆）
```

**素材**：AI 生成 10 张像素素材（`Resources/Slime/`），纯洋红底便于自动抠图。

**顺带修复的既有缺陷**

- `SlimeBoss` **完全没有好感度逻辑** → 史莱姆好感度永远为 0，整个社群无法解锁
- `WorldBossSlime` 漏 `AddFavor` → 打世界 Boss 不涨好感度
- `WorldBossManager` 史莱姆分支为空（其他三社群均已实现）
- 存档界面「好感度装备」只有 0~8 → 场景缺 9/10/11 节点，改为运行时克隆补齐
- `getnewskill` 无法学习 inactive 模板技能（`Instantiate` 继承 inactive → `Start()` 不执行）
- `ChoiceUI` 共享升级卡被重复入池→ 抽中概率翻倍
- `skillupgrade` 单支匹配会**软锁**（`choiceskill == null` 时未关面板，`timeScale` 停在 0）

**技术要点**

- 伴生鱼/太极本体挂**场景根**：Player 靠 `localScale.x` 取负翻转朝向，作为子物体会被镜像
- 精灵尺寸声明为**世界米数**：`Sprite.Create(pixelsPerUnit:100)` 会让 1024px 图变成 10.24 单位
- 命中检测**先判距离后`GetComponent`**：600 敌人时可省下每帧上万次调用
- 敌人禁止移动用**到期时间戳**而非 bool+协程，多次叠加天然幂等；只锁位移，朝向/动画/接触伤害照常

### 2026-08-03 · 数值修复 · 结算面板重构 · 操作文档重写

**「N7 小怪打出上百伤害」** — 难度配置表数值未做任何改动，真正原因是四条既有缺陷叠加：

| 根因 | 说明 |
|---|---|
| static倍率跨局残留 | `endlessHp/AtkMultiplier` 仅在无尽模式分支重置，而「返回主菜单」走 `LoadScene` 重载同场景，C# static **不会**归零 → 打过无尽后选 N7，攻击 = `base × 3.0 × 残留`。`ResetSceneCaches()` 已存在但**全项目无调用点** |
| 难度缩放"原地自乘" | 任何 `SetActive`翻转都会再乘一遍，指数级放大 |
| 蝙蝠俯冲无视护甲 | 全项目唯一不减防御的小怪伤害，玩家堆的 DEF 完全失效 |
| 碰撞伤害无 CD | 仅两个 Boss 自带CD，普通小怪贴身时短时间内多次结算 |

修复：新增幂等 `ApplyDifficultyScaling()`（快照 prefab 原值后从快照重算）；
`ResetSceneCaches` 接入 `RuntimeInitializeOnLoadMethod` + `sceneLoaded` 自动调用；
蝙蝠伤害改为 `Max(1, atk - def)`；碰撞伤害加 0.5s 节流。

**结算面板** — 修复「亡者领域总输出未计算」，根因是四处漏埋点：
友军近战、友军蝙蝠俯冲、孢子领域（独立实现不继承 `Bulletbase`）、风箭（独立结算路径）。

新增统计维度：击杀数 / 承受伤害 / 最高单击 / 治疗量 / 源木 / 复活友军数 / DPS。
承伤治疗采用 `Player.Update` **逐帧差分**的集中式统计，天然覆盖全部 20+ 伤害源。

同时修掉 14 项面板 bug，其中较关键的：

- `ReturnToMain` 漏调 `RecordAcquiredSkills()` → 技能数恒为 0、技能列表恒空
- `Show()` 在 `SetActive(true)` **之前**布局 → 未激活对象 `rect` 为 (0,0) 导致首次打开排版错乱
- NaN 传播链：`RecordDamage` 不校验脏值 → 百分比变 NaN% → 进度条构造抛异常 → **面板白屏**
- 技能名/装备名未转义 `<` → 被 TMP 当标签解析致整行消失
- 返回按钮无防重入（`timeScale=0` 下连点重复 `LoadScene` 致卡死）
