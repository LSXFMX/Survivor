# Survivor — 像素幸存者

一个基于 Unity 的 **2D 像素动漫风 Vampire Survivors-like Rogue-lite 游戏**，拥有丰富的装备收集、多角色皮肤、技能进化树和社群 Boss 玩法。

---

## 项目规模

| 类别 | 数量 |
|------|------|
| 技能系统 | 11 个技能 + 3 个 UR 进化 |
| 角色/皮肤 | 4 个（琪诺露、南筱风、夏无、无罪） |
| Boss 类型 | 10 种（5 基础 + 4 社群 WorldBoss + 1 最终龙王） |
| 难度配置 | 14 个（N1 ~ N13 + 无尽模式） |
| 普通小怪 | 4 种（蘑菇人、蝙蝠、狼人、史莱姆） |
| 装备总数 | ~76 件（成就/通关/抽卡/好感度/继承） |
| 奇遇事件 | 10 个 |
| 社群 | 4 个（蘑菇/蝙蝠/狼人/史莱姆好感度） |

## 游戏特色

### 核心玩法
- **自动战斗 + 走位** — 技能自动向最近敌人释放，玩家只需专注于走位和生存
- **升级三选一** — 每次升级弹出三张卡牌：学习新技能 / 强化已有技能 / 提升人物属性；首轮保底全为学习卡
- **鼠标点击移动** — 支持 WASD/方向键 和鼠标左键点击地面移动，N1 开局自动弹出新手教程
- **倍速系统** — 1x/2x/3x 三档切换（3x 需成就装备解锁）
- **冲刺** — 空格键冲刺，可升级无敌/穿怪

### 养成系统
- **抽卡系统** — R / SR / SSR / UR 四档抽卡，软保底机制，SSR 直接影响局内战斗（解锁技能、进化路线、被动属性）
- **装备系统** — 四种装备类型（成就/通关/抽卡/好感度），持久化解锁，跨局生效；存档界面可查看获得条件
- **好感度社群** — 四个社群（蘑菇/蝙蝠/狼人/史莱姆），击败世界 Boss 积累好感度，分 10/50/100 三档解锁装备和被动加成
- **源木与奇遇** — 局内货币源木，消耗 200 触发随机奇遇二选一/三选一，效果包括临时增益、永久加成、技能强化

### 技能进化
- **风之形** — 飓风 + 风箭 → 永久环绕风刃
- **地狱火** — 火球术 + 风箭 → 从天而降的三叉戟
- **亡者领域** — 孢子领域 → 击杀敌人概率复活为永久友军
- **命途:寄生** — 狼人社群好感度解锁，发射寄生触手吸取生命

### 挑战内容
- **14 个难度** — N1 教学局到 N13 终极龙王 + 无尽挂机模式
  - 关键节点：N3 奇遇 · N4 蝙蝠 · N5 门挑战 · N6 世界 Boss · N7 血攻翻倍 · N8 社群挑战
- **10 种 Boss** — 蘑菇人/蝙蝠/狼人/史莱姆/龙王及对应社群世界Boss
- **门挑战** — N5+ 解锁的 13 层递增挑战，每层通关所有技能升级上限永久 +1，全通额外经验效率 +10
- **世界 Boss** — N6+ 开局生成，属性为关底 Boss 两倍且自带回血，击败解锁对应社群
- **营地攻占** — 战场中出现可占领的中立营地，占领后每秒产出源木
- **对局结算** — 4 页翻页面板：概览（总伤害/DPS/最高单击/击杀/承伤/治疗/源木）、
  技能伤害占比排行、击败首领列表、本局技能与新解锁装备；支持方向键与滚轮翻页

### 其他
- **四位角色皮肤** — UR 角色通过抽卡解锁，各有独特被动与开局自带技能
  - 琪诺露（默认·均衡）/ 南筱风（风系）/ 夏无（火系）/ 无罪（亡者领域本命）
- **读档复活** — R 级读档币在死亡时消耗 1 张原地满血复活，每局限一次
- **自动模式** — 成就装备8「不可视之手」解锁，自动选取升级
- **装备积分** — 每次抽卡获积分，可兑换通关装备；无尽模式每分钟额外 +5
- **七彩蘑菇/孢子异变** — 蘑菇敌人50% 概率随机变色
- **内置操作文档** — 14 页图文教程，N1 开局自动弹出，可从暂停菜单随时重开

## 技术栈

- **引擎**：Unity 2022.3+ (C#)
- **渲染**：2D Sprite + SpriteRenderer
- **摄像机**：透视投影，45° 俯视视角
- **物理**：Unity Physics（3D Rigidbody + BoxCollider/SphereCollider）
- **UI**：Unity uGUI + TextMeshPro (heiti SDF 中文字体)
- **素材**：像素动漫风精灵图（chibi Q 版比例，~2.5 头身）
- **持久化**：PlayerPrefs（装备/好感度/难度解锁/教程标记）
- **摄像机**：Cinemachine CinemachineBrain

4. 首次运行建议从 N1 难度开始，自动弹出新手教程

## 更新日志

### 2026-08-03 — 数值修复 · 结算面板重构 · 操作文档重写

#### 严重数值 Bug 修复：「N7 小怪打出上百伤害」

| 根因 | 说明 | 修复 |
|------|------|------|
| static 倍率跨局残留 | `enemy.endlessHpMultiplier` / `endlessAtkMultiplier` 是 static，仅在无尽模式分支重置。而"返回主菜单"走 `LoadScene` 重载同场景，C# static **不会**归零 → 打过一局无尽后再选 N7，小怪攻击 = `base × 3.0(N7) × 残留倍率`。`ResetSceneCaches()` 虽已存在但**全项目无任何调用点** | `ResetSceneCaches` 接入 `RuntimeInitializeOnLoadMethod` + `sceneLoaded` 自动调用；`battleUI.Start` 与 `title.click_start` 双重保险 |
| 难度缩放"原地自乘" | `atk = RoundToInt(atk * cfg.atkMultiplier)` 在当前值上累乘，任何 `SetActive(false)→(true)`（对象池、亡者领域复活演出）都会再乘一遍，指数级放大 | 新增幂等 `ApplyDifficultyScaling()`：快照 prefab 原值，每次从快照重算 |
| 蝙蝠俯冲无视防御 | `player.health -= (int)atk` 是全项目唯一不减护甲的小怪伤害，玩家堆的 DEF 完全失效 | 改为 `Max(1, atk - player.def)`，与其他敌人统一 |
| 基础碰撞伤害无 CD | 仅 `BossMushroomMan`/`BossBat` 自带 CD，普通小怪贴身时短时间内多次结算 | `enemy.OnCollisionEnter` 增加 0.5s 内置节流 |
| 世界 Boss 双重放大 | prefab 已写死 ×2 值（atk 100），子类 `OnEnable` 又乘一遍难度倍率 | 明确不再叠加难度倍率，并登记缩放基准 |

> 难度配置表（`DifficultyManager`）**一个数字都没有改动**，N7 一直是 HP ×20 / ATK ×3.0。

#### 结算面板：数据补全 + Bug 修复 + 布局重构

**修复「亡者领域总输出未计算」** — 该缺陷由四处漏埋点共同造成：

- `MindControlled.DealMeleeHit` — 友军（复活小怪 / 世界 Boss）近战输出**从未统计**
- `Bat.OnTriggerEnter`（`isAllyMode`）— 友军蝙蝠俯冲伤害**从未统计**
- `BulletSporeField` — 孢子领域（亡者领域的伤害来源）不继承 `Bulletbase`，**从未统计**
- `BulletWindArrow.ApplyWindArrowImpact` — 风箭走独立结算路径，绕过了 `Bulletbase.OnTriggerEnter`，
  导致最核心的基础技能伤害恒为 0

友军输出现统一归入「亡者领域·友军」一行，避免按 rolename 刷出上百行。

**新增统计维度**（均在 `BeginSession` 统一归零，杜绝跨局污染）：
击杀数 · 承受伤害 · 最高单击 · 治疗量 · 源木总量 · 复活友军数 · DPS

- 玩家承伤/治疗采用 `Player.Update` 逐帧差分的**集中式统计**，天然覆盖全部 20+ 个伤害源，
  避免逐一埋点必然出现的遗漏
- 源木埋在 `YuanMuManager.Add`（全项目唯一入口）

**修复的面板 Bug**：

- `battleUI.ReturnToMain` 主结算路径漏调 `RecordAcquiredSkills()` → 「获得技能数」恒为 0、技能列表恒空
- `Show()` 在 `SetActive(true)` **之前**做布局，未激活对象 `rect.size` 可能为 (0,0) 导致布局函数直接
  return → "第一次打开排版错乱，关掉再开才正常"。现改为先激活 + `ForceRebuildLayoutImmediate`
- `RecordDamage` 未校验 NaN/Infinity/负数 → 脏值污染字典后所有百分比变 NaN%，
  `Mathf.RoundToInt(NaN)` 使进度条构造抛异常导致面板白屏
- `FormatNumber(NaN)` 因 `NaN >= x` 恒为 false 会落到末行输出 "NaN"
- 技能名/装备名/Boss 名未转义 `<`，含该字符时会被 TMP 当标签解析致整行消失
- 技能超过 8 个时溢出面板底部且无滚动条 → 现限制 8 行 + "其它 N 项"合并
- `Show()` 可被重复调用 → 玩家翻到第 3 页会被强制拉回第 1 页
- `ShowPage` 在 `pages.Length == 0` 时 `Clamp(x, 0, -1)` 得到 -1，按钮状态错乱
- 圆点数量与页数不一致时索引越界；多余圆点现自动隐藏
- 返回按钮无防重入，`timeScale=0` 下连点会重复 `LoadScene` 导致卡死
- 部分结束路径漏调 `FinalizeSession` → 用时显示 0 秒；`Show()` 现就地补结算
- 装备名只显示"抽卡装备·13"这类无意义 ID → 现从 `EquipmentIcon` 反查真名（如"饮血剑"）
- `AutoScaleFontSizes` 对所有 TMP 启用 autoSizing，导致各页字号忽大忽小、进度条错位 →
  现仅按钮保留自适应，标题与正文固定字号

**UI 布局重构** — 底栏从"三个按钮挤一行"改为两行分区：

```
┌────────────────────────────────────────┐
│ [< 上一页]      ● ○ ○ ○      [下一页 >] │  ← 浏览操作，左右对称，圆点严格居中
│                [ 返回主菜单 ]            │  ← 终结操作，独立居中强调
└────────────────────────────────────────┘
```

旧布局把「下一页」固定在 `x=-180`、「返回」在 `x=-20`，面板宽度小于约 600px 时会盖住居中的圆点；
且三个按钮尺寸各异（110/110/150 宽）导致视觉重心偏右。新布局全部按面板尺寸比例计算并做上下限钳制。

其余视觉调整：概览页改为双列紧凑排布 + 分隔线分组；进度条改用等宽方块字符（`█`/`─`）保证对齐；
正文行距放宽；翻页按钮低饱和、返回按钮绿色强调，建立清晰视觉层次。

**交互增强**：结算面板与操作文档均支持 ← → 方向键、A/D 键与鼠标滚轮翻页；操作文档补上了
注释里承诺过但从未实现的"右键快速关闭"。
